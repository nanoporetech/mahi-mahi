# Configuration Parameters

| Parameter | Description |
|----|----|
| extension | The number of bases to extend on both sides of the region when processing reads. Default: 150. Note that the extension is not included in the calculation of the repeat copy number. |
| min_flank_length | If a read does not initially map to both sides of the region, search again with shorter flanking sequences, until either it does map or this minimum length is reached. Default: 75. Reads that still do not map to both sides will be treated as non-spanning. |
| max_flank_length | After shorter flanks fail to realign, try one longer flank, capped at this length and at the available read-side length. Default: 1000. The longer-flank attempt is skipped when its length would not exceed `extension`. |
| region_merge_distance | The minimum distance allowed between loci that do not touch. Default: 50. (Loci that do touch are merged into a single composite TR.) |
| min_region_coverage | The minimum number of reads required to consider a region valid for analysis. Default: 10. Regions with fewer reads will be flagged as FILTER=LowDepth. |
| min_read_support_per_allele | Specifies the minimum number of reads required to reliably calculate the repeat copy number for an allele. Default: 4. Alleles with fewer reads are flagged as FILTER=LowDepth and use different algorithms. |
| include_extra_trs | Whether to include non-pathogenic parts of multi-TR loci as separate VCF records. Default: true. |
| generate_clustering_plots | Whether to write per-locus read-length KDE clustering PDFs to OUT_DIR/SAMPLE_plots/. Default: true. |
| generate_motif_plots | Whether to write static per-locus motif-composition PDFs to OUT_DIR/SAMPLE_plots/. Default: true. |
| generate_methylation_plots | Whether to add a CpG methylation panel below the motif panel in those PDFs. Ignored unless generate_motif_plots is also true. Default: true. |
| methylation_state_confidence_threshold | Minimum probability for a CpG state to be reported as valid. Lower-confidence states are marked as uncertain and excluded from methylation summaries. Default: 0.80. |
| clustering.non_spanning_read_policy | Whether to include non-spanning reads in clustering and allele size estimation. `default` includes long non-spanning reads to find very long alleles; `exclude` excludes all non-spanning reads and assigns them to allele 0. Default: default. |
| clustering.hap_max_mismatch_fraction | Maximum allowed fraction of haplotagged reads per phaseset that can disagree with their cluster assignment before the clustering is considered inconsistent with haplotags. Default: 0.1. |
| clustering.exclude_haplotag_inconsistent_reads | When clustering and haplotags mostly agree (phased=True), mark reads whose cluster-assigned allele differs from their haplotag as belonging to no allele, and hence exclude them from allele size estimation. Default: false, as it is often the haplotag that is wrong. |
| clustering.plot_first_attempt_density | Include the superseded first density estimate in `--debug` clustering plots when clustering retries with a fallback bandwidth. Default: false. |
| very_wide_cluster_minimum_q75_q50_ratio | Very variable-length alleles, defined as alleles with (75th percentile / 50th percentile) of at least this, use their 75th percentile as their length. This is intended to make it more obvious that the sample has some very long TRs here. Default: 2.0. To turn this feature off entirely, set this to Infinity. |
| strand_bias_run_min_tr_length | Minimum analyzed TR span, in bases, for a read to count as long enough to support running strand-bias analysis at a locus. This is the TR sequence span fed into the strand-bias k-mer analysis, not the full sequencing-read length. Default: 100. |
| strand_bias_run_min_long_tr_fraction | Strand-bias analysis only runs when at least this fraction of reads at the locus have analyzed TR span at or above strand_bias_run_min_tr_length. This avoids triggering the check for loci dominated by short reads with only a few long outliers. Once the gate passes, the existing strand-bias analysis still uses all reads. Default: 0.2. Set this to 0 to disable the gate. |
| strand_bias_kmer_coverage_threshold | Motifs that are strand biased, i.e. whose rate depends on which strand is being read, are a potential sign of error. Each read is flagged as suspicious, is_suspicious=True, if more than this fraction of the read's TR region is a strand-biased kmer. Default: 0.2. To turn strand bias checks off entirely, which is not recommended, set this to Infinity. |
| strand_bias_exclude_suspicious_reads | Whether to exclude suspicious reads from the calculation of the allele's overall parameters. size_and_motifs excludes them from size, copy number and motif counts, motifs_only excludes them only from motif counts, none never excludes them. Default: motifs_only, because this bias usually affects motif composition more than overall length. Note that this applies when there are any suspicious reads, not only when there are enough suspicious reads to flag the locus as FILTER=MotifBias. |
| strand_bias_min_remaining_reads_per_allele | If an allele has fewer than strand_bias_min_remaining_reads_per_allele usable non-suspicious reads and any suspicious reads, flag the locus as FILTER=MotifBias, do not report its motif counts, and keep the suspicious reads included in its length estimates even if strand_bias_exclude_suspicious_reads would normally exclude them. Default: 3. This does not do anything to loci that have low coverage but no suspicious reads: see min_read_support_per_allele to flag those. |
| strand_bias_motif_composition_difference_threshold | If an allele's estimated motif composition changes by more than this much, measured by total variation distance on a 0-1 scale, when suspicious reads are excluded from the estimation, compared to when they are included, flag the locus as FILTER=MotifBias. Default: 0.25. |
| strand_bias_reads_fraction_threshold | If more than this fraction of an allele's reads are flagged as suspicious, flag the locus as FILTER=MotifBias. Default: 0.25. |
| strand_bias_hide_motifs_reads_fraction_threshold | If more than this fraction of an allele's reads are flagged as suspicious, do not report the allele's motif counts, MRCN / median_motif_counts, at all. Default: 0.75. |
| strand_bias_method | Method for strand bias analysis: statistical_testing, default and rigorous statistical filtering, or counts_threshold, simple presence/absence comparison. |
| aba_middle_exact_fraction_threshold | For 3-part motifA / motifB / motifA composites whose middle section is the main sub-TR, collapse the decomposition to the left-only split if the middle segment has fewer exact matches to its expected motif than this fraction. Default: 0.25. Set this to 0 to disable the ABA middle exact-match check. |
